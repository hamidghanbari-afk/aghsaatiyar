اقساط‌یار — نسخه قابل نصب به شکل وب‌اپ (PWA)

محتویات:
- index.html: برنامه اصلی
- manifest.webmanifest: نام، آیکون و تنظیمات نصب
- sw.js: کش اولیه برای اجرای آفلاین پس از اولین بارگذاری موفق
- icons/: آیکون‌های 192 و 512 پیکسلی

روش انتشار ساده:
1) پوشه را از فایل ZIP خارج کنید.
2) محتوای پوشه را در یک سرویس میزبانی استاتیک HTTPS مثل Netlify یا GitHub Pages منتشر کنید.
3) آدرس HTTPS ساخته‌شده را با Google Chrome روی گوشی سامسونگ باز کنید.
4) منوی سه‌نقطه Chrome > Install app یا Add to Home screen را انتخاب کنید.
5) برنامه را یک بار آنلاین باز کنید تا فایل‌ها cache شوند؛ سپس حالت پرواز را برای تست آفلاین امتحان کنید.

نکته مهم درباره اطلاعات:
- برنامه از localStorage استفاده می‌کند؛ داده‌ها در همان مرورگر/مبدأ (دامنه) ذخیره می‌شوند.
- هرگز آدرس میزبانی را عوض نکنید مگر اینکه ابتدا از داخل برنامه پشتیبان بگیرید.
- پاک کردن داده‌های سایت/Chrome یا حذف پروفایل مرورگر می‌تواند اطلاعات را پاک کند.
- رمز ورود برنامه به‌تنهایی رمزگذاری داده‌های ذخیره‌شده نیست. برای اطلاعات حساس، گوشی را با قفل صفحه امن کنید و مرتب پشتیبان بگیرید.
- این فایل به صورت آفلاین پس از اولین بارگذاری موفق طراحی شده؛ فونت Google Fonts ممکن است بدون اینترنت بارگیری نشود.
